# BookingApp

BookingApp is a lightweight Django web application that allows users to register, browse service providers, and book or cancel appointments, all of which can be managed by administrators through the built-in Admin panel (accessible at http://127.0.0.1:8000/admin/ using the preconfigured credentials: username `admin` and password `admin123`). To run the application locally, install the dependencies using `pip install -r requirements.txt`, apply database migrations with `python manage.py migrate`, and start the development server via `python manage.py runserver` before visiting http://127.0.0.1:8000/ in your browser.
